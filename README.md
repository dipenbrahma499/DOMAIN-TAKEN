# Domain Taken — by Dipen

A modern, responsive "This domain is taken" landing page built with pure HTML, CSS, and JavaScript. It features a glassmorphism card, an animated particle network background, a typewriter status line, and full support for every screen size — from tiny foldables to 4K displays.

---

## ✨ Features

- **Glassmorphism card** — translucent, blurred panel with subtle border glow and depth.
- **Animated particle network background** — canvas-based dots that connect to each other and react to your cursor.
- **Typewriter status line** — rotating phrases typed and deleted with a blinking caret.
- **Auto-detect domain** — reads the current hostname and displays it in the domain chip.
- **Contact Owner button** — builds a `mailto:` link automatically using the detected hostname.
- **Fully responsive** — dedicated layouts for:
  - Tiny phones (280px – Galaxy Fold outer)
  - Small & large phones
  - Tablets (portrait & landscape)
  - Desktops & ultrawide monitors
  - 4K / 8K / TV displays
  - Foldables & dual-screen devices
  - Landscape phones (horizontal card layout)
  - Very short screens (condensed padding)
- **Safe area support** — respects notches and dynamic islands via `env(safe-area-inset-*)`.
- **Accessibility** — `prefers-reduced-motion`, `forced-colors`, focus-visible outlines, and semantic markup.
- **Modern CSS** — `clamp()`, `dvh`/`svh`, flexbox everywhere, and CSS custom properties.
